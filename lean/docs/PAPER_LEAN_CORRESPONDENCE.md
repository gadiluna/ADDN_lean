## Reading conventions and assumptions

The scope is every clause of every formal lemma/theorem/corollary, together with all necessary proof dependencies. Bibliographic comparisons and unnumbered observations are outside this statement-level certification. A Lean proof may establish a statement by a different argument from its prose proof.

Notation and standing assumptions are those of each linked paper section. The statement column reproduces the paper's full prose and formulas. Paper-local mathematical macros are expanded, cross-references use their printed numbers, and decorative proof-end symbols and LaTeX labels are omitted.

In Lean theorem names, `exhaustive` refers to the paper's term *full*: the visible level contains every node of the complete history-tree level. For example, Lemma 16 is linked to `Counting.HardnessVisible.first_level_exhaustive`.

The common model uses finite directed multigraphs, permits parallel arcs and self-loops, requires strong connectivity in every round, and supplies each anonymous agent with the known number of leaders. Agents send their previous state and learn their outdegree after sending; halted agents are silent. The lower bound ranges over protocols correct for every admissible population at the fixed leader count.

The runtime statements concern the verified finite-alphabet machine operating on binary-encoded local state, shared view DAGs, and compressed message multiplicities. They charge initialization and all live local transitions. The bound is polynomial in `n + bits(M) + 1`, where `M` bounds the number of physical arcs per round; the paper's assumption `M ≤ 2^(a·n^k)` for fixed `a, k` yields a polynomial in `n`. Each transition starts with the encoded message input already supplied: collecting raw packets or preparing that input tape is not an additional charged operation in this model.

Complexity-class membership and reductions use total binary languages, verified polynomial machine time, and polynomial witness lengths. Malformed vistas have empty spectrum; invalid network encodings are negative instances of `SomeAgentKnows`. The required external complexity results are included in the checked dependency chain.
